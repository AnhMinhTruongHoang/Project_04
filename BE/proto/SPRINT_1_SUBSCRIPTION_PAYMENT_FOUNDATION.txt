============================================================
VII. PHASE 3 — QUALIFIED PLAY
============================================================

Không được tính tiền theo countPlay hiện tại.

countPlay chỉ phù hợp để hiển thị popularity.

Cần lưu play event riêng.


Entity đề xuất:

TrackPlayEvent

Fields:

id
trackId
artistId
listenerId
sessionId
listenedSeconds
trackDurationSeconds
qualified
qualificationReason
country
deviceType
createdAt


Một play được tính qualified khi:

- Track monetization APPROVED.
- User thực sự phát audio.
- listenedSeconds đạt ngưỡng.
- Không phải artist tự nghe track của mình.
- Không phải request bị lặp bất thường.
- Không phải bot.
- Không phải session đã được tính trước đó.


Ngưỡng MVP đề xuất:

requiredSeconds =
min(
    30 giây,
    50% thời lượng track
)


Ví dụ:

Track dài 20 giây:
Nghe ít nhất 10 giây.

Track dài 180 giây:
Nghe ít nhất 30 giây.


Không cộng earning ngay tại endpoint play.

Flow đúng:

Player gửi play event
→ Backend lưu play event
→ Đánh dấu qualified
→ Scheduled job tổng hợp
→ Tạo earning ledger


Mục đích:

- Tránh cộng tiền hai lần.
- Có thể rollback.
- Có thể kiểm tra fraud.
- Có lịch sử giải thích số tiền.

Ý nghĩa:

grossAmount:

platformFee:
Phí nền tảng.

Tiền artist thực nhận.


Công thức:

netAmount =
grossAmount - platformFee


Không dùng:

double

cho tiền.

BigDecimal

Ví dụ Java:

private BigDecimal grossAmount;
private BigDecimal platformFee;
private BigDecimal netAmount;

private String currencyCode;


Nếu toàn bộ hệ thống chỉ dùng VNĐ và không có số lẻ, có thể dùng Long.

Tuy nhiên BigDecimal linh hoạt hơn cho:

- USD.
- Royalty nhỏ.
- Quy đổi tiền tệ.
- Phí phần trăm.

XI. CÁCH TÍNH EARNING
============================================================

Có hai giai đoạn.


GIAI ĐOẠN 1 — MVP ĐƠN GIẢN

Dùng rate cố định theo qualified play.

Ví dụ cấu hình:

earningRatePerQualifiedPlay

Không hardcode trong service.

Tạo bảng:

EarningRateConfig

Fields:

id
sourceType
rate
currency
effectiveFrom
effectiveTo
active


Công thức:

grossAmount =
qualifiedPlayCount × rate


Đây là cách dễ demo và dễ test.


GIAI ĐOẠN 2 — FAN-POWERED EARNINGS

Mỗi listener có một pool riêng.

Ví dụ:

Listener A trả subscription.

Trong tháng:

- 70% thời gian nghe Artist X.
- 20% nghe Artist Y.
- 10% nghe Artist Z.

Pool của Listener A được chia theo tỷ lệ đó.


Công thức:

listenerDistributableRevenue =
listenerNetSubscriptionRevenue
× artistShareRate


artistEarning =
listenerDistributableRevenue
× artistQualifiedListeningSeconds
÷ listenerTotalQualifiedListeningSeconds


Ưu điểm:

- Fan nghe ai thì tiền đi tới artist đó.
- Artist nhỏ vẫn có cơ hội kiếm tiền.
- Giảm tác động của bot loop toàn hệ thống.
- Phù hợp định hướng SoundClone.


Không nên triển khai fan-powered ngay trong sprint đầu.

Phải hoàn thành trước:

- Payment.
- Qualified play.
- Ledger.
- Fraud checks.
- Monthly settlement.

package com.example.demo.entities;

import java.time.LocalDateTime;

import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.Id;
import jakarta.persistence.Index;
import jakarta.persistence.Table;

@Entity
@Table(
        name = "subscription_payments",
        indexes = {
                @Index(name = "idx_subscription_payment_user", columnList = "userId"),
                @Index(name = "idx_subscription_payment_status", columnList = "status"),
                @Index(name = "idx_subscription_payment_created", columnList = "createdAt"),
                @Index(name = "idx_subscription_payment_transaction", columnList = "providerTransactionId")
        })
public class SubscriptionPayment {

    @Id
    @Column(length = 24)
    private String id;

    @Column(nullable = false, unique = true, length = 64)
    private String paymentReference;

    @Column(nullable = false, length = 24)
    private String userId;

    @Column(nullable = false, length = 24)
    private String planId;

    @Column(length = 24)
    private String subscriptionId;

    @Column(nullable = false, length = 32)
    private String planCode;

    @Column(nullable = false, length = 100)
    private String planName;

    @Column(nullable = false)
    private Long amount;

    @Column(nullable = false, length = 8)
    private String currency;

    @Column(nullable = false, length = 32)
    private String provider;

    @Column(length = 128)
    private String providerTransactionId;

    @Column(nullable = false, length = 32)
    private String status;

    @Column(nullable = false, length = 32)
    private String paymentType;

    @Column(length = 500)
    private String failureReason;

    private LocalDateTime paidAt;
    private LocalDateTime failedAt;
    private LocalDateTime refundedAt;
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;

    public String getId() { return id; }
    public void setId(String id) { this.id = id; }

    public String getPaymentReference() { return paymentReference; }
    public void setPaymentReference(String paymentReference) { this.paymentReference = paymentReference; }

    public String getUserId() { return userId; }
    public void setUserId(String userId) { this.userId = userId; }

    public String getPlanId() { return planId; }
    public void setPlanId(String planId) { this.planId = planId; }

    public String getSubscriptionId() { return subscriptionId; }
    public void setSubscriptionId(String subscriptionId) { this.subscriptionId = subscriptionId; }

    public String getPlanCode() { return planCode; }
    public void setPlanCode(String planCode) { this.planCode = planCode; }

    public String getPlanName() { return planName; }
    public void setPlanName(String planName) { this.planName = planName; }

    public Long getAmount() { return amount; }
    public void setAmount(Long amount) { this.amount = amount; }

    public String getCurrency() { return currency; }
    public void setCurrency(String currency) { this.currency = currency; }

    public String getProvider() { return provider; }
    public void setProvider(String provider) { this.provider = provider; }

    public String getProviderTransactionId() { return providerTransactionId; }
    public void setProviderTransactionId(String providerTransactionId) {
        this.providerTransactionId = providerTransactionId;
    }

    public String getStatus() { return status; }
    public void setStatus(String status) { this.status = status; }

    public String getPaymentType() { return paymentType; }
    public void setPaymentType(String paymentType) { this.paymentType = paymentType; }

    public String getFailureReason() { return failureReason; }
    public void setFailureReason(String failureReason) { this.failureReason = failureReason; }

    public LocalDateTime getPaidAt() { return paidAt; }
    public void setPaidAt(LocalDateTime paidAt) { this.paidAt = paidAt; }

    public LocalDateTime getFailedAt() { return failedAt; }
    public void setFailedAt(LocalDateTime failedAt) { this.failedAt = failedAt; }

    public LocalDateTime getRefundedAt() { return refundedAt; }
    public void setRefundedAt(LocalDateTime refundedAt) { this.refundedAt = refundedAt; }

    public LocalDateTime getCreatedAt() { return createdAt; }
    public void setCreatedAt(LocalDateTime createdAt) { this.createdAt = createdAt; }

    public LocalDateTime getUpdatedAt() { return updatedAt; }
    public void setUpdatedAt(LocalDateTime updatedAt) { this.updatedAt = updatedAt; }
}

import com.example.demo.entities.SubscriptionPayment;
import com.example.demo.repositories.SubscriptionPaymentRepository;


//// THÊM CONSTANT

private static final String PAYMENT_PENDING = "PENDING";
private static final String PAYMENT_PAID = "PAID";
private static final String PAYMENT_FAILED = "FAILED";
private static final String PAYMENT_PROVIDER_MOCK = "MOCK";
private static final String PAYMENT_NEW_SUBSCRIPTION = "NEW_SUBSCRIPTION";
private static final String PAYMENT_UPGRADE = "UPGRADE";
private static final String PAYMENT_DOWNGRADE = "DOWNGRADE";
private static final String CURRENCY_VND = "VND";


//// THÊM REPOSITORY

@Autowired
private SubscriptionPaymentRepository subscriptionPaymentRepository;


//// THÊM METHOD — đặt trước private User lockUser(...)

@Transactional
public Map<String, Object> createPaymentOrder(
        String userId,
        String planCode,
        String provider) {

    String normalizedPlanCode = planCode == null
            ? ""
            : planCode.trim().toUpperCase();

    if (normalizedPlanCode.isEmpty()) {
        throw new IllegalArgumentException("Plan code is required");
    }

    SubscriptionPlan requestedPlan = subscriptionPlanRepository
            .findByCodeAndIsActiveTrue(normalizedPlanCode);

    if (requestedPlan == null) {
        throw new IllegalArgumentException("Subscription plan not found");
    }

    if (PLAN_BASIC.equals(requestedPlan.getCode())) {
        throw new IllegalArgumentException(
                "Basic plan does not require payment");
    }

    long amount = requestedPlan.getMonthlyPrice() == null
            ? 0
            : requestedPlan.getMonthlyPrice();

    if (amount <= 0) {
        throw new IllegalStateException(
                "Paid plan price must be greater than zero");
    }

    lockUser(userId);

    UserSubscription currentSubscription =
            getOrCreateCurrentSubscription(userId);

    SubscriptionPlan currentPlan =
            getPlan(currentSubscription.getPlanId());

    if (requestedPlan.getId().equals(currentPlan.getId())) {
        throw new IllegalArgumentException(
                "You are already subscribed to this plan");
    }

    String paymentType =
            resolvePaymentType(currentPlan, requestedPlan);

    String normalizedProvider =
            provider == null || provider.trim().isEmpty()
                    ? PAYMENT_PROVIDER_MOCK
                    : provider.trim().toUpperCase();

    LocalDateTime now = LocalDateTime.now();

    SubscriptionPayment payment = new SubscriptionPayment();

    payment.setId(generateId());
    payment.setPaymentReference(
            "SC-"
                    + UUID.randomUUID()
                            .toString()
                            .replace("-", "")
                            .substring(0, 20)
                            .toUpperCase());
    payment.setUserId(userId);
    payment.setPlanId(requestedPlan.getId());
    payment.setPlanCode(requestedPlan.getCode());
    payment.setPlanName(requestedPlan.getName());
    payment.setAmount(amount);
    payment.setCurrency(CURRENCY_VND);
    payment.setProvider(normalizedProvider);
    payment.setStatus(PAYMENT_PENDING);
    payment.setPaymentType(paymentType);
    payment.setCreatedAt(now);
    payment.setUpdatedAt(now);

    subscriptionPaymentRepository.save(payment);

    return toPaymentResponse(payment);
}


@Transactional
public Map<String, Object> confirmMockPayment(
        String userId,
        String paymentId,
        String providerTransactionId) {

    if (paymentId == null || paymentId.trim().isEmpty()) {
        throw new IllegalArgumentException("Payment id is required");
    }

    String safeTransactionId = providerTransactionId == null
            ? ""
            : providerTransactionId.trim();

    if (safeTransactionId.isEmpty()) {
        throw new IllegalArgumentException(
                "Provider transaction id is required");
    }

    lockUser(userId);

    SubscriptionPayment payment = subscriptionPaymentRepository
            .findByIdAndUserId(paymentId, userId)
            .orElseThrow(
                    () -> new IllegalArgumentException(
                            "Payment not found"));

    if (PAYMENT_PAID.equals(payment.getStatus())) {
        return toPaymentResponse(payment);
    }

    if (!PAYMENT_PENDING.equals(payment.getStatus())) {
        throw new IllegalArgumentException(
                "Only pending payment can be confirmed");
    }

    SubscriptionPayment duplicatedTransaction =
            subscriptionPaymentRepository
                    .findByProviderAndProviderTransactionId(
                            payment.getProvider(),
                            safeTransactionId)
                    .orElse(null);

    if (duplicatedTransaction != null
            && !duplicatedTransaction.getId().equals(payment.getId())) {
        throw new IllegalArgumentException(
                "Provider transaction already exists");
    }

    Map<String, Object> subscriptionResult =
            subscribe(userId, payment.getPlanCode());

    String activatedSubscriptionId =
            extractSubscriptionId(subscriptionResult);

    LocalDateTime now = LocalDateTime.now();

    payment.setSubscriptionId(activatedSubscriptionId);
    payment.setProviderTransactionId(safeTransactionId);
    payment.setStatus(PAYMENT_PAID);
    payment.setPaidAt(now);
    payment.setUpdatedAt(now);

    subscriptionPaymentRepository.save(payment);

    Map<String, Object> result = new LinkedHashMap<>();

    result.put("payment", toPaymentResponse(payment));
    result.put("subscription", subscriptionResult);

    return result;
}


@Transactional(readOnly = true)
public List<Map<String, Object>> getMyPayments(
        String userId) {

    return subscriptionPaymentRepository
            .findByUserIdOrderByCreatedAtDesc(userId)
            .stream()
            .map(this::toPaymentResponse)
            .collect(Collectors.toList());
}


private String resolvePaymentType(
        SubscriptionPlan currentPlan,
        SubscriptionPlan requestedPlan) {

    if (currentPlan == null
            || PLAN_BASIC.equals(currentPlan.getCode())) {
        return PAYMENT_NEW_SUBSCRIPTION;
    }

    long currentPrice = currentPlan.getMonthlyPrice() == null
            ? 0
            : currentPlan.getMonthlyPrice();

    long requestedPrice = requestedPlan.getMonthlyPrice() == null
            ? 0
            : requestedPlan.getMonthlyPrice();

    return requestedPrice > currentPrice
            ? PAYMENT_UPGRADE
            : PAYMENT_DOWNGRADE;
}


@SuppressWarnings("unchecked")
private String extractSubscriptionId(
        Map<String, Object> subscriptionResult) {

    if (subscriptionResult == null) {
        return null;
    }

    Object subscriptionObject =
            subscriptionResult.get("subscription");

    if (!(subscriptionObject instanceof Map)) {
        return null;
    }

    Map<String, Object> subscriptionData =
            (Map<String, Object>) subscriptionObject;

    Object id = subscriptionData.get("id");

    return id == null ? null : String.valueOf(id);
}


private Map<String, Object> toPaymentResponse(
        SubscriptionPayment payment) {

    Map<String, Object> result = new LinkedHashMap<>();

    result.put("id", payment.getId());
    result.put("paymentReference", payment.getPaymentReference());
    result.put("planId", payment.getPlanId());
    result.put("planCode", payment.getPlanCode());
    result.put("planName", payment.getPlanName());
    result.put("subscriptionId", payment.getSubscriptionId());
    result.put("amount", payment.getAmount());
    result.put("currency", payment.getCurrency());
    result.put("provider", payment.getProvider());
    result.put(
            "providerTransactionId",
            payment.getProviderTransactionId());
    result.put("status", payment.getStatus());
    result.put("paymentType", payment.getPaymentType());
    result.put("failureReason", payment.getFailureReason());
    result.put("paidAt", payment.getPaidAt());
    result.put("failedAt", payment.getFailedAt());
    result.put("refundedAt", payment.getRefundedAt());
    result.put("createdAt", payment.getCreatedAt());
    result.put("updatedAt", payment.getUpdatedAt());

    return result;
}

@PostMapping("/payments/checkout")
public ResponseEntity<?> createPaymentOrder(
        @RequestBody CreateSubscriptionPaymentDTO dto,
        HttpServletRequest request) {

    try {
        User user = getCurrentUser(request);

        if (user == null) {
            return ResponseEntity
                    .status(401)
                    .body(new ApiResponse<>(
                            401,
                            "Unauthorized",
                            null));
        }

        if (dto == null) {
            return ResponseEntity
                    .badRequest()
                    .body(new ApiResponse<>(
                            400,
                            "Request body is required",
                            null));
        }

        Map<String, Object> data =
                subscriptionService.createPaymentOrder(
                        user.getId(),
                        dto.getPlanCode(),
                        dto.getProvider());

        return ResponseEntity.ok(
                new ApiResponse<>(
                        200,
                        "Payment order created",
                        data));

    } catch (IllegalArgumentException e) {
        return ResponseEntity
                .badRequest()
                .body(new ApiResponse<>(
                        400,
                        e.getMessage(),
                        null));

    } catch (Exception e) {
        e.printStackTrace();

        return ResponseEntity
                .status(500)
                .body(new ApiResponse<>(
                        500,
                        e.getMessage(),
                        null));
    }
}
