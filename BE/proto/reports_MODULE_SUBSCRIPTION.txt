============================================================
II. TỔNG QUAN MODULE
============================================================

Module Subscription quản lý quyền sử dụng Artist Studio theo từng gói.

Mục tiêu:

1. Quản lý 3 gói BASIC, ARTIST và ARTIST_PRO.
2. Tự cấp BASIC cho user chưa có subscription.
3. Quản lý trạng thái ACTIVE và EXPIRED.
4. Quản lý chu kỳ subscription theo tháng.
5. Quản lý quota upload theo số giây audio.
6. Phân quyền distribution, monetization, schedule release, insights và benefits.
7. Làm nguồn dữ liệu cho Artist Studio.
8. Chuẩn bị nền tảng để tích hợp thanh toán thật.
9. Không triển khai AI Mastering.

Trạng thái hiện tại:
Đã hoàn thành core backend.
Chưa tích hợp payment thật.
Chưa nối toàn bộ dữ liệu vào frontend Artist Studio.

VI. NGHIỆP VỤ SUBSCRIPTION SERVICE
============================================================

1. getPlans()

- Lấy các plan đang active.
- Sắp xếp theo monthlyPrice tăng dần.


2. getMySubscription(userId)

- Tìm subscription ACTIVE.
- Nếu chưa có thì tự tạo BASIC.
- Kiểm tra currentPeriodEnd.
- Tạo hoặc lấy usage hiện tại.
- Trả plan, subscription và usage.


3. subscribe(userId, planCode)

- Chuẩn hóa planCode thành chữ hoa.
- Kiểm tra plan tồn tại và đang active.
- Nếu đang dùng đúng plan thì giữ nguyên.
- Nếu đang có plan khác:
  plan cũ chuyển EXPIRED.
- Tạo subscription ACTIVE mới.
- Tạo usage mới.


4. cancel(userId)

- Không cho hủy BASIC.
- Gói trả phí được đặt cancelAtPeriodEnd = true.
- Quyền vẫn còn đến hết currentPeriodEnd.


5. getAccessForUser(userId)

Trả quyền chuẩn hóa:

planCode
unlimitedUploads
uploadLimitSeconds
uploadedSeconds
remainingSeconds
canDistribute
canMonetize
canScheduleRelease
hasMembershipBenefits
advancedInsightsDays


6. addUploadedSeconds(userId, uploadedSeconds)

- Cộng số giây upload vào usage hiện tại.
- Bỏ qua nếu uploadedSeconds <= 0.


7. Hết chu kỳ

Nếu cancelAtPeriodEnd = false:
- Tự gia hạn thêm một tháng.

Nếu cancelAtPeriodEnd = true:
- Plan cũ chuyển EXPIRED.
- Tự tạo BASIC.
- Tạo usage mới cho BASIC.

X. TÍCH HỢP TRACK UPLOAD
============================================================

Backend phải kiểm tra quota trước khi lưu file.

Luồng:

1. Nhận multipart upload.
2. Đọc user từ JWT.
3. Gọi:

subscriptionService.getAccessForUser(user.getId())

4. Nếu không unlimited:

remainingSeconds =
uploadLimitSeconds - uploadedSeconds

5. Nếu duration audio lớn hơn remainingSeconds:

HTTP 403

{
  "statusCode": 403,
  "message": "Upload quota exceeded",
  "data": null
}

6. Nếu hợp lệ:
Tiếp tục upload và save Track.

7. Sau khi save thành công:

subscriptionService.addUploadedSeconds(
    user.getId(),
    audioDurationSeconds
)

Yêu cầu bổ sung:
Track nên có field:

private Long durationSeconds;

XI. SQL KIỂM TRA DATABASE
============================================================

1. Kiểm tra plan

SELECT
    id,
    code,
    name,
    monthlyPrice,
    uploadMinutesLimit,
    unlimitedUploads,
    canDistribute,
    canMonetize,
    canScheduleRelease,
    hasMembershipBenefits,
    isActive
FROM subscription_plans
ORDER BY monthlyPrice ASC;


2. Kiểm tra subscription

SELECT
    id,
    userId,
    planId,
    status,
    startedAt,
    currentPeriodStart,
    currentPeriodEnd,
    cancelAtPeriodEnd,
    createdAt,
    updatedAt
FROM user_subscriptions
ORDER BY createdAt DESC;


3. Kiểm tra usage

SELECT
    id,
    userId,
    subscriptionId,
    periodStart,
    periodEnd,
    uploadedSeconds,
    createdAt,
    updatedAt
FROM subscription_usages
ORDER BY createdAt DESC;


4. Subscription ACTIVE của một user

SELECT *
FROM user_subscriptions
WHERE userId = 'USER_ID'
  AND status = 'ACTIVE'
ORDER BY createdAt DESC;


5. Usage hiện tại

SELECT *
FROM subscription_usages
WHERE userId = 'USER_ID'
  AND periodStart <= NOW()
  AND periodEnd > NOW()
ORDER BY createdAt DESC;
