Mục tiêu:
- Ở trang /track/... chỉ cho WaveTrack / WaveSurfer phát audio thật.

- Chỉ render duy nhất 1 AppFooter trong toàn app.

3. APPFOOTER - PAUSE AUDIOPLAYER KHI Ở /track
==================================================

Trong app.footer.tsx, tìm useEffect điều khiển audio:

useEffect(() => {
  const audio = playerRef.current?.audio?.current;
  if (!audio) return;

  ...
}, [...]);

Đổi thành:

useEffect(() => {
  const audio = playerRef.current?.audio?.current;
  if (!audio) return;

  if (shouldUseWaveFooter) {
    suppressFooterAudioEventRef.current = true;

    audio.pause();
    audio.currentTime = 0;

    window.setTimeout(() => {
      suppressFooterAudioEventRef.current = false;
    }, 0);

    return;
  }

  if (previousTrackUrlRef.current !== currentTrack?.trackUrl) {
    audio.currentTime = 0;
    previousTrackUrlRef.current = currentTrack?.trackUrl || "";
  }

  if (currentTrack?.isPlaying === false) {
    audio.pause();
    return;
  }

  if (currentTrack?.isPlaying === true) {
    audio.play();
  }
}, [
  currentTrack?._id,
  currentTrack?.trackUrl,
  currentTrack?.isPlaying,
  shouldUseWaveFooter,
]);

Nhớ có ref này ở đầu AppFooter:

  const safeVolume = Math.max(0, Math.min(1, footerTrack.volume));
  const safeMuted = Boolean(footerTrack.muted || safeVolume === 0);

  latestVolumeRef.current = safeVolume;
  latestMutedRef.current = safeMuted;
  latestVolumeIdRef.current = footerTrack.volumeId;

  wavesurfer.setVolume(safeMuted ? 0 : safeVolume);
}

11. WAVETRACK - SEEK TỪ FOOTER KHÔNG ĐƯỢC PLAY AUDIOPLAYER
==================================================

Trong WaveTrack, đoạn seek từ footer-control nên giữ:

if (typeof footerTrack.seekTime === "number") {
  const seekId = footerTrack.seekId ?? footerTrack.seekTime;

  if (lastHandledSeekIdRef.current === seekId) return;

  lastHandledSeekIdRef.current = seekId;

  const waveDuration = wavesurfer.getDuration();

  if (waveDuration) {
    const nextTime = Math.min(
      Math.max(Number(footerTrack.seekTime), 0),
      waveDuration
    );

    wavesurfer.setTime(nextTime);
    setTime(formatTime(nextTime));
    lastSyncSecondRef.current = Math.floor(nextTime);
  }

  return;
}

Quan trọng:
- Sau khi xử lý seek phải return;
- Không để rơi xuống play/pause phía dưới nếu chỉ đang tua.

==================================================
KẾT LUẬN
==================================================

Nếu bug dual audio/mute quay lại, check theo thứ tự:

1. AppFooter có bị render nhiều lần không.
2. Trên /track có còn render <AudioPlayer /> không.
3. WaveTrack có ghi đè mất volume/muted khi timeupdate không.
4. useWavesurfer có destroy instance cũ không.
5. ListeningHistory trên /track có set source="footer" sai không.

Rule cuối:
- /track: WaveSurfer là audio thật, AppFooter chỉ control.
- page khác: AppFooter AudioPlayer là audio thật.
