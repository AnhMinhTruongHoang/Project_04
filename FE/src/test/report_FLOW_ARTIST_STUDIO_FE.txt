============================================================
I. MỤC TIÊU CỦA ARTIST STUDIO
============================================================

Artist Studio là khu vực dành cho artist quản lý hoạt động âm nhạc của mình.

Mục tiêu chính:

1. Quản lý các track đã upload.
2. Hiển thị trạng thái kiểm duyệt và copyright.
3. Theo dõi quota upload theo subscription plan.
4. Hiển thị thống kê tổng hợp của artist.
5. Phân quyền Distribution, Monetization, Insights và Benefits.
6. Hiển thị quyền hiện tại của BASIC, ARTIST và ARTIST_PRO.
7. Cho phép admin quản lý Artist Pro Membership Benefits.
8. Chuẩn bị nền tảng cho payment, distribution và monetization thật.
9. Không triển khai AI Mastering trong phạm vi hiện tại.

VIII. FLOW UPLOAD VÀ CẬP NHẬT QUOTA
============================================================

1. User mở trang upload.
2. User chọn title, description, category, image và audio.
3. Frontend gửi multipart request POST /api/v1/tracks.
4. Backend đọc user từ JWT.
5. Backend kiểm tra dữ liệu bắt buộc.
6. Backend tính SHA-256 của audio.
7. Backend kiểm tra audio trùng.
8. Backend đọc durationSeconds.
9. Backend lấy subscription access.
10. Backend kiểm tra remainingSeconds.
11. Backend upload image và audio.
12. Backend lưu Track và cộng uploadedSeconds trong cùng transaction.
13. Nếu quota không đủ, trả HTTP 403 với message Upload quota exceeded.
14. Nếu Track save lỗi, rollback quota và xóa file ảnh/audio đã upload.
15. Nếu hai request upload đồng thời, backend khóa user bằng PESSIMISTIC_WRITE.
16. Khi đổi plan, giữ nguyên uploadedSeconds trong chu kỳ hiện tại.

Hạn chế frontend hiện tại:

Sau upload thành công, Artist Studio có thể cần reload để quota và stats cập nhật.

Chưa có global event hoặc callback tự refresh Artist Studio ngay sau upload.

============================================================
XII. CÁC LỖI ĐÃ GẶP VÀ CÁCH XỬ LÝ
============================================================

1. getAdminArtistBenefitsApi is not defined

Nguyên nhân:

Hàm được export trong api.ts nhưng benefitsTable.tsx chưa import runtime function.

Cách xử lý:

Import các hàm get/create/update/toggle/delete từ @/utils/api.

Interface global không cần import type, nhưng runtime function bắt buộc phải import.

2. No static resource api/v1/admin/artist-benefits

Nguyên nhân:

Backend chưa có controller mapping /api/v1/admin/artist-benefits.

Cách xử lý:

Tạo AdminArtistBenefitController với đầy đủ CRUD mapping.

3. MUI Tooltip bọc disabled button

Nguyên nhân:

Disabled button không phát event để Tooltip bắt.

Cách xử lý:

Bọc button bằng span.

4. bis_skin_checked hydration warning

Nguyên nhân:

Browser extension hoặc phần mềm bảo mật chèn thuộc tính vào DOM.

Cách xử lý:

Không cần sửa source. Có thể test bằng Incognito hoặc tắt extension.

5. studioTabs is not defined

Nguyên nhân:

artistStudioView.tsx vẫn dùng studioTabs nhưng đã xóa import.

Cách xử lý:

Import lại studioTabs từ artistStudioData.ts.

6. Route admin không khớp

File cũ tạo route /benefits nhưng menu trỏ /dashboard/benefits.

Cách xử lý:

Chuyển file tới src/app/(admin)/dashboard/benefits/page.tsx.

7. Stats hiển thị 0 dù track có plays

Nguyên nhân:

ArtistStudioStats chỉ nhận plan, không nhận stats API và dùng defaultStats bằng 0.

Cách xử lý:

- Tạo GET /api/v1/artist-studio/stats.
- Gọi getArtistStudioStatsApi().
- Truyền stats={studioStats} vào ArtistStudioStats.

8. Benefit vẫn hard-code

Nguyên nhân:

ArtistStudioView import studioBenefits từ artistStudioData.ts.

Cách xử lý:

- Tạo GET /api/v1/artist-studio/benefits.
- Tạo admin CRUD.
- Gọi API trong frontend.
- Xóa studioBenefits khỏi data file.


============================================================
XIII. CÁC VẤN ĐỀ CÒN TỒN TẠI
============================================================

1. Distribution chưa có chức năng thật

Hiện trạng:

- Tab tồn tại.
- Permission đã có.
- Button đã mở hoặc khóa theo plan.
- Chưa có view.
- Chưa có entity.
- Chưa có API.
- Chưa có trạng thái phát hành.

2. Vinyl Records chưa có chức năng thật

Hiện trạng:

- Tab chỉ là placeholder.

3. Comments tab chưa có chức năng thật

Hiện trạng:

- Stats đã đếm comment.
- Track detail đã có comment.
- Artist Studio Comments tab chưa có view/API riêng.

API đề xuất:

GET /api/v1/artist-studio/comments

Chức năng đề xuất:

- Lấy toàn bộ comment trên track của artist.
- Filter theo track.
- Search.
- Reply.
- Delete hoặc hide.
- Pagination.

4. Benefits tab riêng chưa render dữ liệu thật

Hiện trạng:

- ArtistBenefits đang render ở cuối trang.
- Tab Benefits trong StudioTabs vẫn có thể đang đi vào placeholder.

Cần sửa:

Khi activeTab === "benefits", render ArtistBenefits trong vùng tab và không render cố định ở cuối trang.

Hoặc xóa tab Benefits nếu muốn benefits luôn hiển thị ở cuối trang.

Không nên vừa có tab Benefits vừa render benefits cố định bên ngoài tab.

5. Stats chưa đầy đủ

Đã thật:

- plays
- likes
- comments
- fans

Chưa thật:

- reposts
- downloads
- earnings

6. Không tự refresh sau upload

Hiện trạng:

- Upload thành công.
- Quota và stats có thể chỉ cập nhật sau khi reload Artist Studio.

Cần làm:

- React context hoặc event.
- router.refresh().
- refetch subscription.
- refetch stats.
- refetch tracks.

7. Không có pagination cho track table

Hiện trạng:

- Load toàn bộ track.
- Filter và search ở client.

Cần làm:

GET /api/v1/tracks/my-tracks?page=0&size=20&search=&status=

8. Admin Benefits chưa upload ảnh trực tiếp

Hiện chỉ nhập imageUrl.

Cần làm sau:

POST /api/v1/admin/artist-benefits/upload-image

Body multipart: image

9. Admin endpoint cần kiểm tra role chắc chắn

Backend phải đảm bảo ROLE_ADMIN cho /api/v1/admin/artist-benefits/**.

10. Permission Distribution và Monetization mới chủ yếu ở UI

Khi triển khai API thật, backend phải gọi SubscriptionService để kiểm tra canDistribute và canMonetize.

11. Payment chưa có

Hiện change-plan kích hoạt plan trực tiếp để test.

Chưa có:

- checkout
- payment transaction
- webhook
- invoice
- refund
- trial
- proration
- grace period

12. Schedule release chưa có

Plan có canScheduleRelease nhưng chưa có field releaseAt, scheduler job, UI chọn ngày giờ và backend publish đúng thời điểm.

13. Session token đang đọc bằng any

Hiện tại dùng (session as any).

Cần mở rộng NextAuth Session type để dùng session.accessToken rõ ràng.

14. Error state chưa thống nhất

Cần chuẩn hóa ApiError, Toast, HTTP 401, HTTP 403 và retry HTTP 500.

15. Artist Studio có nhiều API gọi riêng

Hiện trang gọi subscription, stats, benefits và tracks.

Có thể tạo aggregate endpoint GET /api/v1/artist-studio/overview nếu cần giảm request, nhưng không bắt buộc trong MVP.

16. Benefits ảnh phụ thuộc backend static resource

Production cần đảm bảo upload directory persistent, domain đúng, reverse proxy phục vụ /uploads/**, validate MIME type và giới hạn kích thước ảnh.

17. Delete benefit hiện là hard delete

Có thể đổi thành soft delete bằng isDeleted và deletedAt hoặc chỉ dùng active = false.

18. Earning nên dùng BigDecimal

Khi triển khai monetization, nên dùng BigDecimal earnings và currencyCode.

19. Next.js 14.0.2 outdated

Không làm hỏng Artist Studio. Nên upgrade sau khi module ổn định và test regression.

- Subscription UI.
- Upload quota.

- Distribution.
- Vinyl Records.
- Comments workspace.
- Reposts.
- Downloads.
- Earnings.
- Schedule release.
- Payment.
- Auto refresh sau upload.

Artist Studio shell/UI: Hoàn thành.

Benefits: Hoàn thành mức MVP.

Khoảng 80% nếu phạm vi là Artist Studio quản lý track + subscription + benefits.
